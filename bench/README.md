# bench

Shared workspace — files, not messages. Desks don't talk to each other;
they leave artifacts and read each other's work (per the `bench-read` skill).

## artifact types

- findings — scan results, analysis output, data
- verdicts — a desk's assessment of another desk's findings
- drafts — work-in-progress documents, proposals
- reports — summaries, dashboards, status updates

## how to read (per `bench-read`)

1. List the directory. 2. Read journals first — context matters.
3. Read artifacts second. 4. Summarize state and what needs attention.

Another desk's verdict is input, not authority. Assess independently.
